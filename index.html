02 / Services

What I can build for you

I work on both server and client, so I can take a feature from idea to shipped without handing it off.

Combat & abilities

Hitboxes, combos, cooldowns, summons and status effects, with damage validated on the server so exploiters can't fake hits.

Game loops & rounds

Intermissions, stages, matchmaking pads, objectives and win conditions that keep players in the next round.

Data & saving

Player data with session locking, retries and migrations: inventories, currencies and progress that don't get lost.

UI & menus

Clean, animated interfaces like character select, HUDs, shops and settings that scale across PC, mobile and console.

World systems

Custom water and waves, mounts, swimming, doors and access control: the systems that make a world feel real.

Tools & Python

Studio plugins, build pipelines and Python scripts that automate the boring parts of making a game.
